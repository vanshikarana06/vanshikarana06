## Featured Projects

<details>
<summary><strong>⚖️ LAC — Legal AI Advisor (RAG-Based)</strong></summary>
<br/>

A retrieval-augmented generation system that answers legal queries by grounding LLM responses in curated legal document corpora, reducing hallucination and improving factual reliability.

| Attribute | Detail |
|---|---|
| **Stack** | Python, LangChain, Vector Databases, FastAPI, LLM APIs |
| **Scale** | Multi-document legal corpus with semantic chunking |
| **Performance** | Context-grounded responses with source-traceable retrieval |
| **Security** | Domain-restricted retrieval to minimize hallucinated legal advice |
| **Impact** | Most technically complex and marketable project in portfolio |
| **Repository** | [github.com/vanshikarana06/lac](https://github.com/vanshikarana06/lac) |

LAC was engineered to demonstrate a full RAG pipeline end-to-end: document ingestion, chunking, embedding, vector retrieval, and grounded generation. The system prioritizes traceability — every answer can be mapped back to its source document — which is critical in a domain where fabricated information carries real consequences.

</details>

<details>
<summary><strong>🔍 DeiVs — Dual-Input CNN for Image Forgery Detection</strong></summary>
<br/>

A digital image forensics system that identifies authentic vs. tampered images using a Dual-Input Convolutional Neural Network analyzing images through two distinct streams — spatial and forensic.

| Attribute | Detail |
|---|---|
| **Stack** | Python, TensorFlow/Keras, OpenCV, CNN (dual-stream architecture) |
| **Scale** | Trained on labeled authentic vs. tampered image datasets |
| **Performance** | Dual-stream fusion for higher discrimination between real and edited regions |
| **Security** | Forensic-grade, compression-artifact-based tamper localization |
| **Impact** | Combines spatial and forensic analysis for robust forgery detection |
| **Repository** | [github.com/vanshikarana06/DeiVs](https://github.com/vanshikarana06/DeiVs) |

DeiVs analyzes images through two lenses simultaneously: a **Spatial Stream** on raw RGB data that detects visual inconsistencies, edge anomalies, and lighting mismatches, and a **Forensic Stream** using Error Level Analysis (ELA) that surfaces JPEG compression artifacts to flag regions with differing error levels — a strong signal of localized editing. The dual-input design lets the model cross-validate findings from both streams for more reliable tamper detection.

</details>
