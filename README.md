## Featured Projects

<details open>
<summary><strong>⚖️ LAC: Legal AI Advisor (RAG-Based)</strong></summary>
<br/>

A retrieval-augmented generation system that answers legal queries by grounding LLM responses in curated legal document corpora, reducing hallucination and improving factual reliability.

| | |
|---|---|
| **Stack** | Python, LangChain, Vector Databases, FastAPI, LLM APIs |
| **Scale** | Multi-document legal corpus with semantic chunking |
| **Highlights** | Context-grounded responses with source-traceable retrieval; domain-restricted retrieval to minimize hallucinated legal advice |
| **Repository** | [github.com/vanshikarana06/lac](https://github.com/vanshikarana06/lac) |

LAC demonstrates a full RAG pipeline end to end: document ingestion, chunking, embedding, vector retrieval, and grounded generation. It prioritizes traceability, so every answer maps back to its source document, which matters in a domain where fabricated information carries real consequences.

</details>

<details>
<summary><strong>🔍 DeiVs: Dual-Input CNN for Image Forgery Detection</strong></summary>
<br/>

A digital image forensics system that separates authentic from tampered images using a dual-input convolutional neural network that analyzes each image through two streams: spatial and forensic.

| | |
|---|---|
| **Stack** | Python, TensorFlow/Keras, OpenCV, dual-stream CNN |
| **Data** | Trained on labeled authentic vs. tampered image datasets |
| **Highlights** | Dual-stream fusion for stronger discrimination between real and edited regions; compression-artifact-based tamper localization |
| **Repository** | [github.com/vanshikarana06/DeiVs](https://github.com/vanshikarana06/DeiVs) |

The **Spatial Stream** works on raw RGB data to catch visual inconsistencies, edge anomalies, and lighting mismatches. The **Forensic Stream** uses Error Level Analysis (ELA) to surface JPEG compression artifacts, flagging regions with differing error levels, a strong signal of localized editing. The model cross-validates findings from both streams for more reliable detection.

</details>
